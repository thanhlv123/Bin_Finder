## Scope & design

`src/bin_finder/search/editorial_quality_gate.py` implements a **read-only quality advisory**, not a model-generated quality verdict and not a second schema gate.

- Explicit editor-owned `EditorialQualitySpecification` contains 1–12 bounded, unique coverage requirements; each lists observable positive phrases. These phrases are **edited in advance**, not autogenerated from the same model whose plan is being assessed, to avoid circular evaluation.
- `review_editorial_quality(plan, spec)` considers only **what an AI actually requests for visual content**: `visual_brief`, `must_show`, and `search_queries[].text`. It deliberately **never counts source_anchor** (which repeats source narration) or `must_not_show` (negative constraints) as evidence that an element is covered.
- Simple normalized whole-phrase matching is deterministic and transparent. A phrase match is merely a **textual hint**, NOT a claim that an existing clip depicts that element. False negatives/synonyms and false positives remain possible, so reports always say `quality-review-required` and `heuristic-textual-coverage-not-visual-proof`.
- Fixed review flags: `editorial-coverage-incomplete`, `generic-visible-criteria`, `missing-somber-or-suspense-transition`, `single-shot-editorial-compression-review`. None auto-rejects content or rewrites existing shots.
- Returns `human_editorial_review_required=true`, `footage_verified=false`, `rights_approved=false`, `timeline_approved=false`; independent source verification and media selection remain future steps.
