# F001.5 — Fixed workspace and workflow renumbering

Acceptance changes:

- Main splitter handles are removed. Workspace geometry is controlled by layouts and fixed side-column dimensions.
- Project/scene column: 330 px fixed width.
- Review/export column: 650 px fixed width.
- Source/options panel: 250 px fixed height.
- Search results: 3 cards per row, no horizontal result scrolling.
- Review preview uses KeepAspectRatio so the complete candidate frame is visible.
- Export destination input is reduced and option labels are compacted for reliable display at Windows desktop sizes.
- Workflow panel numbering is now sequential: 1 Project, 2 Scenes, 3 Search Options, 4 Results, 5 Review, 6 Selected, 7 Export.
