# F001.2 — Final GUI Workflow

This milestone implements the final layout approved after Windows screenshots.

## Changes

1. Panel 2 providers are compact checkboxes.
2. Panels 1/4 and 2/5 are independent vertical columns so panel 2 can stay compact while panel 5 grows.
3. Panel 5 uses a wider result grid and explains that clicking a card sends it to panel 3.
4. Panel 3 clears stale candidate state when the scene changes and enables selection only after a result is previewed.
5. Selecting in panel 3 marks the scene selected in panel 4.
6. Panel 7 displays selected scene cards and replaces the previous candidate when the same scene is reselected.
7. Panel 8 uses a compact two-column export-option layout.
8. Demo-selected scenes are now visibly seeded into panel 7.

F002 will replace demo candidates with provider-backed discovery results.
